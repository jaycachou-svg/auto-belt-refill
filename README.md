# Auto Belt Refill

A [D2RLoader](https://d2rloader.net) plugin for Diablo II: Resurrected that
keeps your potion belt filled from the inventory.

《暗黑破坏神2：重制版》的 D2RLoader 插件：从背包自动补满腰带药水栏。

## Downloads / 下载

Two packages, same plugin, different documentation language.
两个内容相同的整合包，仅文档语言不同——选一个下载即可。

| Folder / 文件夹 | Language | For |
|---|---|---|
| [`Auto-belt-refill-v0.35.8-EN/`](./Auto-belt-refill-v0.35.8-EN/) | English | English-speaking players |
| [`Auto-belt-refill-v0.35.8-CN/`](./Auto-belt-refill-v0.35.8-CN/) | 简体中文 | 中文玩家 |

Each package mirrors the D2RLoader directory layout: copy the `plugins\` and
`config\` folders into your `d2rloader\` folder and restart the game.
每个包都按登录器目录结构排好：把 `plugins\` 和 `config\` 两个文件夹拖进
`d2rloader\` 目录，重启游戏即可。

- Tested with / 已实测：D2RLoader 1.1.0-beta / 1.2.1-beta, D2R 3.2.0 (92777) / 3.3.0 (93854).
- Details / 详情: see the README inside either folder / 见任一文件夹内的 README。
